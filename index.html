WARISAN BUDAYA NUSANTARA

Kekayaan Bahasa & Budaya Suku Mandar

Mandar adalah suku maritim dan agraris terkemuka di pesisir barat Sulawesi (Sulawesi Barat), terkenal dengan perahu bercadik Sandeq, sarung tenun Saqbe, serta falsafah hidup yang luhur.

Falsafah Hidup Mandar

1. Siri' anna Pacce

Menjaga martabat, harga diri (siri'), integritas moral serta rasa empati dan kesetiakawanan yang mendalam (pacce) terhadap sesama manusia.

2. Siwaliparriq

Prinsip gotong-royong sejati. Bersama-sama memikul beban suka dan duka dalam kehidupan bermasyarakat, baik di laut maupun di darat.

3. Pitu Babana Binanga & Pitu Ulunna Salu

Persatuan tujuh kerajaan muara sungai di pesisir pantai dan tujuh kerajaan di hulu sungai pegunungan yang saling melengkapi.

Ciri Khas Bahasa Mandar

1. Huruf Hamzah / Glottal Stop (' atau q)

Bahasa Mandar sering menggunakan perhentian glottal di tengah atau akhir kata, ditulis dengan tanda petik (') atau huruf (q). Contoh: kaka' / kakaq, indo' / indoq, saqbe.

2. Keragaman Dialek

Memiliki ragam dialek yang kaya seperti Dialek Balanipa (baku/umum), Sendana, Pamboang, Banggae, dan Malunda.

3. Tingkatan Tutur Santun

Menggunakan kata Tabe' (permisi/santun) dan sapaan penghormatan seperti Kita' kepada orang yang lebih tua atau dihormati.

Ikon Kebanggaan Mandar

1. Perahu Sandeq

Perahu layar kayu bercadik teramah lingkungan dan tercepat di dunia, mampu menaklukkan gelombang samudra hingga ke Jawa dan Singapura.

2. Lipa Saqbe Mandar

Sarung sutra tenun tangan warisan leluhur dengan aneka corak geometris klasik seperti Sure' Penghulu, Sure' Bunga, dan Sure' Marasa.

3. Kuliner Jepa & Bau Peapi

Makanan pokok sehat dari olahan singkong (Jepa) yang disantap bersama kuah ikan kuning asam mangga khas Mandar (Bau Peapi).

Panduan Deploy Online GitHub Pages (Gratis)

Website ini sudah dirancang 100% siap online melalui layanan gratis GitHub Pages tanpa biaya server selamanya!

1

Buat Repository Baru di GitHub

Buka github.com/new, beri nama repository misalnya: kamus-bahasa-mandar, dan pilih Public.

2

Upload Seluruh File & PDF

Pastikan file PDF Anda diberi nama persis:

Kamus Bahasa Mandar-Indonesia.pdf

Sistem web ini secara otomatis membaca file PDF dengan nama tersebut begitu diunggah ke GitHub.

3

Aktifkan GitHub Pages (1-Klik)

Di halaman repository GitHub Anda, masuk ke menu:
Settings ➔ Pages ➔ Di bawah Branch pilih main atau master (folder /root) ➔ Klik Save.

4

Website Langsung Aktif & Bisa Diakses Gratis!

Dalam 1-2 menit, website resmi kamus sudah aktif di alamat:

https://[username-github].github.io/[nama-repo]/

Bisa dibuka dari HP Android, iPhone, tablet, maupun komputer oleh seluruh masyarakat Mandar!
